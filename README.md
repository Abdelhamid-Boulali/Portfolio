# Abdelhamid Boulali — Portfolio

Portfolio responsive en HTML/CSS/JS, inspiré de l'ambiance visuelle de la référence fournie :
- vert profond + orange
- typographie éditoriale
- hero avec carte de code
- projets, expérience, services, méthode, stack et contact
- responsive desktop/tablette/mobile

## Installation
Ouvrir `index.html` dans un navigateur.

## À personnaliser
Dans `index.html`, remplacer :
- `VOTRE_EMAIL@example.com`
- le lien GitHub
- le lien LinkedIn
- les projets par tes vrais projets si tu veux afficher des captures d'écran.
